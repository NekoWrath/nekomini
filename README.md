# 🎮 Streamer Telegram Mini App (TMA) Full Solution

Полноценное, готовое к продакшену решение **Telegram Mini App для стримеров и контент-мейкеров** с глубокой интеграцией Telegram WebApp SDK, темным геймерским интерфейсом (Glassmorphism & Neon Glow), бэкендом на FastAPI и ботом на `aiogram 3.x`.

---

## 🌟 Возможности и Структура Приложения

### 1. 📅 Вкладка «Расписание и Календарь»
* **Интерактивный календарь на неделю** с фильтрацией по дням (Пн–Вс).
* **Live-баннер со статусом «🔴 В ЭФИРЕ»**, пульсирующей анимацией и счетчиком зрителей.
* **Таймер обратного отсчета** (Дни : Часы : Минуты : Секунды) до ближайшего запланированного стрима.
* **Кнопка «🔔 Напомнить о стриме»**: сохраняет подписку в базе и автоматически присылает пуш через бота за 15–30 минут до начала эфира.
* **Интеграция с Telegram `MainButton`**: закрепленная нативная кнопка внизу экрана для моментального перехода на трансляцию (Twitch, Kick, VK Видео, YouTube).

### 2. 💡 Вкладка «Предложка и Вопросы»
* **Лента предложений и вопросов** от зрителей с категориями:
  * 🎮 *Идея для игры*
  * ❓ *Вопрос стримеру*
  * 🔥 *Челлендж*
  * 💬 *Другое*
* **Система голосования (Upvotes/Likes)** с оптимистичным UI-обновлением и тактильным откликом (`HapticFeedback`).
* **Фильтры**: «Новые», «Популярные (по голосам)», «Отвеченные», «Мои предложения» + поиск по ключевым словам.
* **Статусы**: «⏳ На рассмотрении», «✅ Взято на стрим», «❌ Отклонено», «💬 Отвечено».
* **Карточка ответа стримера**: стилизованный блок с аватаром стримера, цитатой ответа и бейджем подтверждения.
* **Модальное окно подачи идеи** с выбором категории, подробным описанием и опциональной ссылкой на медиа/клип.

### 3. 🔔 Вкладка «Уведомления и Настройки»
* **Профиль зрителя**: Telegram-аватар, имя, `@username`, Telegram ID и бейдж роли.
* **Переключатели пуш-уведомлений**:
  * 🔴 *Старт трансляций* (уведомление при запуске эфира).
  * 📢 *Важные анонсы и новости* (розыгрыши, важные объявления).
  * 💬 *Ответы на мои предложения* (уведомление в ЛС, когда стример отвечает на идею).
* **Каналы стримера**: быстрые переходы на Twitch, Kick, VK Видео и Telegram-канал.

### 4. 🛡️ Админ-панель (для Стримера и Модераторов)
* **Аналитика в реальном времени**: количество подписчиков бота, идей на рассмотрении, стримов и голосов.
* **Модерация предложки**: кнопки «Взять на стрим», «Отклонить», «Ответить». При ответе бот **автоматически отправляет личное сообщение автору в Telegram**!
* **Конструктор расписания**: добавление, редактирование и удаление стримов, указание платформы, тегов и баннера.
* **Переключатель «🔴 В эфире»**: моментальный запуск стрима с возможностью автоматической рассылки уведомлений подписчикам.
* **Мгновенные анонсы и рассылка**: создание и отправка сообщения с фото и кнопкой перехода всем подписчикам бота в 1 клик.

## 🛠 Технологический стек

* **Frontend**:
  * React 18, Vite, Tailwind CSS (Custom Gamer Dark Palette).
  * Lucide React Icons, date-fns (русская локализация).
  * Telegram WebApp SDK (`window.Telegram.WebApp` / `@twa-dev/sdk`), Haptic Feedback, Telegram Theme Params, MainButton.
* **Backend**:
  * Python 3.11+, FastAPI, Pydantic v2.
  * SQLAlchemy (Async), aiosqlite (SQLite).
  * Cryptographic HMAC-SHA256 валидация `initData`.
  * APScheduler (фоновый планировщик для проверки стримов и отправки пушей).
* **Telegram Bot**:
  * `aiogram 3.x` (современный асинхронный фреймворк для Telegram ботов).
  * Команды: `/start`, `/schedule`, `/suggest`, `/admin`, `/help`.

## 🚀 Быстрый запуск в «Один клик»

Мы подготовили интерактивный мастер запуска, который сам запросит все ключи, ссылки на каналы, установит зависимости и поднимет все сервисы:

### 🎮 Запуск одной командой:

```bash
# На Mac / Linux:
./start.sh

# Или через Python (кроссплатформенно на Windows / Mac / Linux):
python3 start.py
```

Мастер в терминале последовательно спросит:
1. **Токен Telegram бота** (из `@BotFather`)
2. **Ваш личный Telegram ID** (из `@userinfobot`)
3. **Имя стримера**
4. **Ссылки на Twitch, Kick, VK Видео и Telegram-канал**
5. **HTTPS URL для Mini App** (или оставит локальный для тестов)

Скрипт автоматически создаст файл `.env`, виртуальное окружение `venv`, установит все библиотеки и запустит Бэкенд, Бота и Фронтенд одновременно!

## 🛠 Ручной запуск (по шагам)

#### А. Запуск Бэкенда (FastAPI + Bot):
```bash
cd backend

# Создаем виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Создаем файл настроек .env
cp .env.example .env
# Отредактируйте .env (укажите BOT_TOKEN и ADMIN_IDS)

# Запускаем сервер
python main.py
```
*API будет доступно на:* `http://localhost:8000` (Swagger UI: `http://localhost:8000/docs`).

#### Б. Запуск Фронтенда (React + Vite):
```bash
cd frontend

# Устанавливаем зависимости
npm install

# Запускаем dev-сервер
npm run dev
```
*Фронтенд запустится на:* `http://localhost:5173`.

> 💡 **Browser Dev Mode (Тестирование без Telegram):**  
> При открытии `http://localhost:5173` в обычном браузере вверху появится панель переключения ролей (**«👤 Зритель»** / **«🛡️ Стример»**). Вы можете сразу проверять расписание, отправлять идеи, голосовать и модерировать контент без необходимости каждый раз открывать Telegram!

### 3. Тестирование внутри Telegram через ngrok

Telegram Mini App требует обязательного наличия **HTTPS**. Для локального тестирования на телефоне используйте `ngrok` или Cloudflare Tunnel:

```bash
# Проброс порта фронтенда в интернет
ngrok http 5173
```

1. Скопируйте полученный HTTPS URL (например: `https://abcd-1234.ngrok-free.app`).
2. Вставьте его в `backend/.env` в параметр `WEBAPP_URL=https://abcd-1234.ngrok-free.app`.
3. Установите этот URL в Menu Button через `@BotFather`.
4. Откройте вашего бота в Telegram на смартфоне или Desktop и нажмите кнопку запуска!

### 4. Развертывание через Docker Compose (Production)

Для развертывания на VPS сервере в 1 команду:

```bash
# 1. Склонируйте репозиторий и перейдите в папку
cd busy-newton

# 2. Создайте файл окружения в backend/.env
cp backend/.env.example backend/.env
nano backend/.env  # укажите боевые BOT_TOKEN, ADMIN_IDS и WEBAPP_URL

# 3. Запустите контейнеры
docker-compose up -d --build
```

Docker Compose автоматически соберет:
- **`tma_streamer_frontend`**: Nginx + скомпилированный React SPA на порту 80/3000.
- **`tma_streamer_backend`**: FastAPI API + aiogram 3.x бот + APScheduler + SQLite база данных.

## 🔒 Безопасность и Валидация Telegram WebApp

Бэкенд валидирует входящий заголовок `X-Telegram-Init-Data` строго по спецификации Telegram:
1. Вычисляется `secret_key = HMAC_SHA256("WebAppData", BOT_TOKEN)`.
2. Строка параметров сортируется по алфавиту и хэшируется с `secret_key`.
3. Полученный хэш сверяется с переданным параметром `hash` через `hmac.compare_digest`.
4. Это на 100% исключает возможность подделки личности зрителя или прав администратора.
